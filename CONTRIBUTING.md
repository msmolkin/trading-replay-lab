# Contributing

Read `AGENTS.md` first. Contributions should correspond to a task in `tasks/README.md` or explain why a new task is needed.

## Before opening a pull request

1. Confirm dependencies for the task are merged.
2. Keep changes within the task's owned paths.
3. Add tests and run the affected checks.
4. Update contracts and documentation when behavior changes.
5. Confirm no market data, credentials, signed URLs, or hidden episode timestamps are present in the diff.

Use Conventional Commit subjects, for example `feat(sim): implement reduce-only crossing guard`.
